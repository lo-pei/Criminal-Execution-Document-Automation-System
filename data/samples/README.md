# 真实判决样本（回归用）

这里放的是**真实生效刑事判决书的完整正文**，用于回答一个问题：CEDAS 的抽取
规则在真实文书上到底认不认得对。

本目录**不入库**（`.gitignore` 中 `data/samples/*`，见 `SECURITY.md`「真实案件
材料一律不入库」）。新克隆的仓库里只有本说明，`tests/test_samples.py` 的用例
会 skip 而不是 fail——那是预期行为。

## 来源

| 项 | 说明 |
| :--- | :--- |
| 数据库 | 元典智库（经 MCP 检索接口取得） |
| 采集时间 | 2026-11-01 |
| 条数 | 18 份 |
| 筛选条件 | 一审刑事判决书；按援引法条与标题定向检索（如 `cite:刑法第七十一条` 找先减后并） |
| 文书范围 | 首部（法院、案号、公诉机关、各被告人）至落款（审判人员、日期、书记员）全文 |

### 为什么不用北大法宝

北大法宝的案例接口只返回**判决主文摘要**，没有首部、没有落款、没有多被告人
的分别记载，做不了「谁判了什么」的抽取回归。元典智库返回完整正文，才有条件
验证被告人切块、主文归属、强制措施抽取这些真正容易出错的地方。

`data/public-corpus/` 里的 36 条主文摘录仍来自北大法宝，两者分工不同：
那份语料回归的是**刑期计算口径**（`tools/corpus_regress.py`），
本目录回归的是**抽取规则**。

## 用途与边界

- ✅ 用来回归抽取规则（`tests/test_samples.py`），逐人断言姓名、罪名、决定
  执行刑期、并罚形态、缓刑考验期、载明起止日、免刑与「主文无判项」两类结论
- ✅ 用来发现解析器没覆盖的真实写法（见下节）
- ❌ **不用于调参**——规则只照《字段字典》与文书样式写，样本只做验收。
  看着样本改正则，测试分数会涨，真实命中率不会
- ❌ **不覆盖清洗层**。数据库导出的是已分段文本：每段一行、段尾带标点、
  没有软换行、没有页眉页码。清洗层的核心工作恰好是处理这些噪声，而这批样本
  里一样都没有。清洗层由 `examples/S000` 的 TXT/PDF 双通道回归（见
  `tests/test_samples.py::test_pdf_channel_matches_txt`）
- ❌ 不用于对外报数。18 份是定向抽样，不是随机抽样，不能据以推断全国文书的
  命中率

`tools/sample_lint.py` 对两种来源用不同判据：`--source db`（默认，本目录）只查
「行长是否被人工切整齐」「有无网页残留」，`--source pdf` 才查页眉页码与软换行。

## 这批样本抓出来的真实缺陷

换成真实判决后第一次跑，规则错了 8 处。列在这里是因为**这些错在自编样本上
永远不会暴露**——自编的时候，写样本的人和写规则的人是同一个人，用同一套想象。

| 现象 | 真实文书的写法 | 根因 |
| :--- | :--- | :--- |
| 案号抽空，连带 A003 + A004 | （2014）甬余刑初字第633号 | 案号规则要求「刑初」后直接跟数字，漏了「字第」 |
| 被告人一个都认不出 | 「被告人颜某。曾因犯盗窃罪……」 | 姓名正则要求姓名后是逗号，原文是句号 |
| 羁押起始日全空 | 「2013年9月28日因涉嫌抢劫罪被……刑事拘留」 | 正则要求「日」后紧跟「被」，中间夹着案由 |
| 「同年7月10日」被跳过 | 「于2020年7月8日被抓获，同年7月10日被……刑事拘留」 | 年份只在措施句里取，「抓获」不是措施，年份丢失 |
| 住址抽成一串羁押经过 | 「依法监视居住，同月6日被……刑事拘留」 | 住址正则的「住」误命中「监视居住」 |
| 罪名 2 个抽成 4 个 | 「被告单位某某公司1犯虚开增值税专用发票罪……」 | 单位判项被当续段归给自然人 |
| 前罪罪名混进本案 | 「撤销……对被告人张某祥犯聚众斗殴罪……缓刑宣告」 | 撤销缓刑那一项被当成本案定罪 |
| 两人形态串了 | 说理段同一句写两人：「宿某建……撤销假释……张某祥……撤销缓刑」 | 形态判定吃了说理段，段落归属只能给一个人 |

第二轮补进 S013–S017（单位犯罪、再审、26 人、无期）之后，又错了 9 处：

| 现象 | 真实文书的写法 | 根因 |
| :--- | :--- | :--- |
| 缓刑三年零六个月被静默截成 36 个月 | 「判处有期徒刑三年，缓刑三年零六个月」 | 缓刑正则把「年」吃进捕获组，取到「三年」就结束，「零六个月」丢掉。不报错、不留空，值还是整数 |
| 「缓刑六个月」完全解析失败 | 拘役案件的缓刑普遍只有月数 | 缓刑正则只认「…年」，不认月 |
| 免刑判项罪名抽空 | 「二、原审被告人纪某犯盗窃罪，免予刑事处罚。」 | 罪名靠「犯X罪，判处Y」配对，免刑没有「判处」，整条落空 |
| 再审文书 0 名被告人 | 首部写「原审被告人纪某。」 | 姓名正则只认「被告人X，」，不认再审称谓，且姓名后是句号 |
| 再审的并罚形态判成撤销缓刑 | 「一、撤销本院（2014）……刑事判决及……刑事裁定」 | 「撤销」+「缓刑」同现即判第 77 条。再审的「撤销」撤的是原判 |
| 再审改判判成撤销缓刑 | 「二、撤销……刑事判决中第二项，即……判处有期徒刑六个月，缓刑六个月」 | 同上：撤销的对象是判项，「缓刑六个月」只是那一项的内容 |
| 载明起止日一个都抽不到 | 「自二O一四年三月三日**起至**二O一八年三月二日。」 | 年份只认 `\d{4}`（原文用拉丁字母 O 代零），且正则硬性要求「日止」 |
| 说理兜底彻底失效 | 「本院认为……」独立成段，「判决如下：」另起一段 | 只在含「判决如下」的那一段里找说理，独立成段就永远取不到，形态回落到第 69 条 |
| 无判项的被告人报成「抽漏了」 | 再审维持原判：主文三项全在说另一个人 | 连报「罪名缺失／主刑未识别／无起算日」，而原文本来就没有他的判项 |

第三轮补进 S018（二审改判、七人一案）之后，又错了 4 处：

| 现象 | 真实文书的写法 | 根因 |
| :--- | :--- | :--- |
| 七名被告人只认出 1 个 | 「上诉人（原审被告人）张某宾（绰号白宾）。」 | 姓名正则只认段首「被告人」「原审被告人」，二审的标准称谓「上诉人（原审被告人）」整批漏掉；姓名后也不是逗号，而是绰号括号 |
| 第一个当事人随案号一起消失 | 「（2011）汴刑终字第28号」下一行直接是第一个上诉人 | 案号行以「号」收尾、不以句读收尾，清洗层把它和下一段并成一段，段首既不是称谓也不是案号 |
| 七个人的起止日全归最后一人 | 「即张某宾自……止；张某新自……止；……孙某甲自……止」 | 一个括号里七组日期，段落只归属于最后一个判项的被告人；按「取第一个匹配」，谢某龙拿到张某宾的十一年（他实际六年） |
| 「维持原判」的三人漏标无判项 | 主文只写「维持……第五、六、七项」，姓名只出现在刑期注释段 | 判据是「主文零出现该姓名」，而注释段把七个人的姓名连着日期列了一遍 |


## 上游数据瑕疵（保留原文，未改写）

| 案号 | 原文 | 说明 |
| :--- | :--- | :--- |
| （2018）豫07刑初35号 | 「2013年6月14日被**北京市中级人民法院**判处死刑，缓期二年执行」 | 北京的中级法院分第一、第二、第三，没有「北京市中级人民法院」这一层级。上游原文如此，样本按原样保留——改写上游文本就等于自己造样本，样本的价值会消失 |
| （2014）梁刑初字第12号 | 「被告人张某祥在缓刑考验期限内犯新罪，应当**撤销假释**」 | 张某祥是缓刑不是假释，应为「撤销缓刑」。同样按原样保留 |

这两处不影响抽取，但值得记住：**上游数据会脏**，凡是依赖第三方文本的环节都要
能容忍它错。
