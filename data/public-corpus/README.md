# 公开语料（回归用）

这里放的是**真实裁判文书的主文摘录**，用于回答一个问题：CEDAS 里写死的计算规则，
和法院真实的写法对不对得上。

## 来源

| 项 | 说明 |
| :--- | :--- |
| 数据库 | 北大法宝·司法案例库（经 MCP 检索接口取得） |
| 筛选条件 | 一审、判决书、基层人民法院；罪名分四批：盗窃罪 / 危险驾驶罪 / 故意伤害罪 / 诈骗罪 |
| 排序 | 审结日期倒序（取 2026 年 9–10 月） |
| 采集时间 | 2026-10-31 |
| 条数 | 36 条（另有 3 条因主文为空或字段错乱被剔除，见文末） |

每条记录都保留了法宝原文链接（`url` 字段），可逐条回原文核对。**这是抽样，不是穷尽检索**，
不能据以推断全国文书的写法分布。

```json
{
  "id": "PKU-0016",

  "court": "安徽省桐城市人民法院",
  "judged_on": "2026-09-30",
  "charges": ["危险驾驶罪"],
  "batch": "危险驾驶罪",
  "result": "被告人彭某犯危险驾驶罪，判处拘役一个月十五天，并处罚金人民币三千元。(……自2026年9月30日至2026年11月13日止。)"
}
```

`result` 是判决主文的相关片段，**逐字摘录，未做改写**；只删去了「如不服本判决，可在
接到判决书的第二日起十日内……」这段上诉告知，因为它与刑期计算无关。

## 用途与边界

- ✅ 用来回归 `cedas.calc` 的刑期计算，见 `tools/corpus_regress.py`
- ✅ 用来发现解析器没覆盖的真实写法
- ❌ **不用于训练抽取规则的正则**——那等于用测试集调参，命中率会虚高。
  规则只照《字段字典》和文书样式写，语料只做验收。
- ❌ 不再分发。当事人姓名已由法宝化名为「某」，但法院名称与案号是真实的。
  本仓库转公开前必须移除本目录。
