# 构建【Win7 + Win10 通用】交付包所需的固定版本。
#
# 这是推荐的默认构建配方：产出一份包，同时能在 Windows 7 与 Windows 10 上运行。
#
# 构建机要求：python.org 官方 CPython **3.8.10**（Windows 7 支持链的终点），
# 安装时勾选 `tcl/tk and IDLE`。
#
#   python -m venv .venv-build
#   .venv-build\Scripts\activate
#   pip install -r requirements-build-win7.txt
#
# 版本选择的硬约束（均已用 pip download --python-version 38 实测）：
#   · pymupdf 1.23.26 是最后一个提供 cp38 轮子的版本，1.24+ 已无 cp38；
#   · python-docx 1.2.0 无 cp38 轮子，须停在 1.1.2；
#   · MarkupSafe 3.x 要求 Python 3.9+，须用 2.1.5；
#   · PyInstaller 6.10.0 有 cp38 轮子，6.11+ 不再保证。
#
# 注意：Python 3.8 已于 2024-10 停止维护。内网离线环境不涉及在线攻击面，
# 但这也意味着不能靠升级依赖修复漏洞——升级前须先确认 Win7 机器已退役。
# 详见 ADR-013。

pymupdf==1.23.26
python-docx==1.1.2
docxtpl==0.20.2

# 传递依赖一并锁定：3.8 的可用版本窗口很窄，交给 pip 解析会随时间漂移
MarkupSafe==2.1.5
lxml==6.1.3
typing_extensions==4.13.2

# 打包工具
pyinstaller==6.10.0
pyinstaller-hooks-contrib==2024.10
