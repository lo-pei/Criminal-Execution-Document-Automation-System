# 04 · 样本格式与标注规范

> 本文规定「送进系统的样本长什么样」与「真值怎么填」。**不按本规范采集的样本，回收后需重做。**

---

## 1. 样本采集

### 1.1 为什么用 TXT

因保密要求，开发阶段不提供 PDF，只提供人工从 PDF 阅读器中「全选 → 复制」得到的纯文本。生产环境仍以 PDF 为唯一输入（见 ADR-005）。

### 1.2 采集步骤（务必照做）

1. 用 PDF 阅读器打开判决书，`Ctrl+A` 全选，`Ctrl+C` 复制。
2. 粘贴到纯文本编辑器（记事本 / Notepad++），**不要**粘贴到 Word。
3. 另存为 UTF-8 编码，扩展名 `.txt`。
4. 命名：`{样本编号}__{案号}.txt`，例：`S001__京0105刑初123号.txt`。
5. 若案号中含 `/` 等文件系统非法字符，改为 `-`，并在真值表备注中注明原始案号。

### 1.3 三条硬性要求

| # | 要求 | 原因 |
|---|---|---|
| 1 | **不得手工删除页眉、页脚、页码** | 样本必须保留真实噪声。清理过的样本会让清洗规则「假通过」，上线后仍被噪声击穿 |
| 2 | **不得手工整理断行、不得补标点** | 软换行与断句是清洗层的核心处理对象，人工整理等于把待解问题删掉 |
| 3 | **不得脱敏到破坏格式** | 姓名可换、日期可换，但「被告人张三，男，1985年3月2日出生」的句式结构必须保留，否则规则失效 |

### 1.4 样本覆盖度

垂直切片阶段：同一法院、同一模板版本、同一时期，20 份。目的不是覆盖多样性，而是把单一样本族的规则写稳。

横向扩展阶段：按「法院 + 年份 + 模板版本」再切 2–3 组，每组 10 份。**不要一次性喂混杂样本**——会写出互相冲突的规则。

### 1.5 训练集 / 留出集切分

按「法院 + 年份」整组切分，**不得随机切分**。同一法院同一年的判决书版式几乎相同，随机切分会让留出集与训练集高度同源，命中率虚高。

建议比例 7:3。留出集在规则开发期间**不得查看**，只在阶段性回归时使用。

## 2. 真值填写

真值表由 `tools/make_truth_template.py` 生成，输出 `data/truth/00-真值填写表.xlsx`。

### 2.1 结构

| Sheet | 内容 | 一行代表 |
|---|---|---|
| `填写说明` | 规则与步骤 | — |
| `A-主体` | 身份与强制措施 | 一名被告人在一份判决书中 |
| `B-量刑` | 罪名、刑期、附加刑 | 同上 |
| `C-刑期` | 载明起止日、羁押起始日 | 同上 |
| `D-程序` | 程序性字段与原文片段 | 同上 |
| `字段说明` | 每个字段的类型、示例、填写规则 | — |
| `枚举值` | 下拉选项全集 | — |

四张填写表按字段字典的 A/B/C/D 四组划分，`样本编号 + 被告人序号` 为跨表主键，四表行序严格对齐。

### 2.2 填写规则

1. **一人一行。** 共同犯罪有 3 名被告人就填 3 行，字段不得合并。
2. **照抄不推断。** 刑期写「有期徒刑三年六个月」，不要自己换算成 42 个月；系统负责换算。
3. **缺失留空并说明。** 判决书未载明的字段留空，在 `D-程序` 的「缺失字段与原因」列写明，例：`出生日期：仅载明年龄`。
4. **日期统一 `YYYY-MM-DD`。** 原文本「二〇二二年三月一日」→ `2022-03-01`。
5. **金额只填数字。** 「罚金人民币五万元」→ `50000`，不带单位、不带千分位。
6. **多罪名最多填 3 个。** 超过 3 个在第 3 个罪名里合并写明并加备注。
7. **原文片段必填三处。** 案号行、被告人首行、判决主文首段——这三段是规则回归的锚点，缺任一处该样本不可用于回归。

### 2.3 为什么要填原文片段

真值只记「值」，无法验证规则是否抽对了位置。片段能回答：这条规则是从哪段文字抽出来的、是否抽错了同名但不同人的段落。**片段是真值表的第二重校验。**

### 2.4 常见错误（回收时重点查）

| 错误 | 表现 | 后果 |
|---|---|---|
| 把「决定执行刑期」填成各罪刑期之和 | B 表 `决定执行刑期` 与 `罪名1刑期` 相同 | 数罪并罚样本失去校验价值 |
| 出生日期按年龄反推 | 判决书写「现年 45 岁」，真值填了推算日期 | 污染 C 组刑期计算 |
| 未羁押案件填了刑期起止日 | 取保候审案件 C 表有起止日 | 规则会学到不存在的模式 |
| 片段截取得太短 | 只填「判决如下」 | 无法定位，回归失败 |
| 跨表行序错位 | A 表第 5 行与 B 表第 5 行不是同一人 | 全部校验失效 |

## 3. 样本体检

采集完成后执行：

```bash
python tools/sample_lint.py data/samples
```

检查项：编码是否可识别、是否疑似被人工整理（段落过少 / 无短行）、是否为空、文件名是否合规、是否存在 BOM 混乱。**不通过的不进入回归集。**
