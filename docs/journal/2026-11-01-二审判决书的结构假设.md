# 二审判决书打破了三处结构假设

2026-11-01 · S018（2011）汴刑终字第28号

## 为什么去采二审

前 17 份样本全是一审（含三份再审）。再审和二审常被当成一类——都「不是一审」，
都要「维持／撤销／改判」三分项。但它们的首部结构完全不同：

- 再审：「原审被告人纪某。」
- 二审：「上诉人（原审被告人）张某宾（绰号白宾）。」

差的是前面六个字和后面的一个括号。规则是按前者写的，所以后者整批漏。

这份文书挑得也巧：七名被告人、五个罪名、改判四人维持三人。它不是那种「结构复杂
但规则跑得过去」的样本——一跑就崩，七个人只认出一个。

## 四处错误，一个共同根因

先说结果：抽出来的七个人是「张某宾、张某新、张某生、谢某龙」四个改判的，
加上「胡某月、田某甲、孙某甲」三个没有判项的。修之前只认出一个人——孙某甲，
七个人里唯一写成「原审被告人孙某甲。」的那位。

四处错误：

**一、称谓。** `_NAME_RE` 只认段首「被告人」「原审被告人」。「上诉人（原审被告人）」
这六个字的前缀不在其中。而且姓名后面不是逗号：写「张某宾（绰号白宾）。」，
终端符是左括号。

**二、案号吞段。** 这个查了一会儿。正则本身没问题——单独测「上诉人（原审被告人）
张某宾（绰号白宾）。」，能抽出「张某宾」。问题在清洗层：案号行「（2011）汴刑终字
第28号」以「号」收尾，不以句读收尾，而清洗层判「上一段以句读结尾才断段」，
于是把案号和下一行并成了一段：

```
（2011）汴刑终字第28号上诉人（原审被告人）张某宾（绰号白宾）。
```

段首既不是称谓、也不再是案号，这个人就没了。真实样本里合并的是「原公诉机关……」
所以侥幸没踩到——但换一份文书，案号下面直接是第一个上诉人，就必踩。

顺带说明：这一条是自编用例先发现的。第一版单元测试里我把案号写在第一行、
当事人写在第二行，跑出来 `['李四', '王五']`，缺张三。如果只跑真实样本，
这个缺陷会一直藏着。

**三、七个人的起止日挤在一个括号里。** 主文最后一个判项后面跟着：

```
（刑期从判决执行之日起计算。……即张某宾自2010年2月27日起至2021年2月26日止；
张某新自2010年2月27日起至2020年2月26日止；……孙某甲自2010年2月26日起至
2011年2月25日止）。
```

七组日期在一段里。段落归属只能给一个人——最后那个判项的谢某龙。他六年，
拿到的是张某宾的十一年。不报错，值还挺「像」。

**四、维持原判的三个人。** 胡某月、田某甲、孙某甲在主文里只有一句「维持……第五、
六、七项」。上一轮为 S017 造的 `verdict_absent` 判据是「主文零出现该姓名」——
到这份文书上失效了，因为那段刑期注释把七个人的姓名连着日期列了一遍。

## 修法上的三个判断

**能用字面标记，就不要用段落位置。** 四处错误里三处是同一个毛病：规则依赖了排版
位置。位置在一审里稳定，在二审里不稳定；而姓名、「被告人X」这类字面标记在两个
审级里都稳定。所以：

- 起止日不再「取本段第一个匹配」，改为按「姓名紧接在『自』之前」认领；
- 无判项不再判「姓名出现过没有」，改判「有没有『被告人X』这个判项称谓」。

**认不出时不取，比取错好。** 载明值只用于校验（ADR-017）。校验拿错数据的后果比
没有数据严重：它会把一个**正确**的推算值标成 V1 不一致，让人去改一个本来就对的值。
所以同段多组日期时，认不出就不给——宁可少一条校验，不能让校验说谎。

验证方式也在这里：起算日填 2010-02-27（真实羁押日）后，七个人的 V1 全部消失。
如果谢某龙拿的还是张某宾的 2021-02-26，他六年的刑期必然报 V1——它没报，
说明七组日期一组都没串。

**判据的反例要写在 ADR 里，不能只写在代码注释里。** ADR-018 初版第 3 条明确写着
「判据是整篇主文没出现过这个名字」，还写了理由。S018 直接给了反例。修订时把反例
原样抄进 ADR——一个被推翻的判据比一个从没被验证过的判据更值得留档，因为它证明
这条路走不通。

## 结果

- 18 份样本、7 名被告人的二审判决：人数、姓名、罪名、刑期、形态、载明起止日全对
- 335 项测试（+6），ruff 干净，`sample_lint.py` 18 份全过
- 前 17 份样本逐份复核：抽取结果无一处变化
- ADR-018 修订第 3 条，新增 ADR-019

## 还没做的

- 「被告人A、B共同犯…」一句定两人（S018 里仍有「被告人张某宾、张某新组织、领导」
  这类写法，但在说理段，不影响判项）
- 主文锚点写「判决：」而非「判决如下」：S018 的原审引述用了「判决：」，但那是
  被引述的原判，不是本案主文，所以这一条仍未真正覆盖
- 涉黑 20 人以上 × 十余罪名：S018 是七人 × 五罪名，人数与罪名的乘积还没到那个量级
