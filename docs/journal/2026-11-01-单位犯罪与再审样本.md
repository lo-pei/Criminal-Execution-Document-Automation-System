# 第二批真实样本：单位犯罪、再审、26 人、无期

> 上一轮 [`2026-11-01-样本改用真实判决.md`](2026-11-01-样本改用真实判决.md) 用 12 份
> 真实判决替掉自编样本，一次抓出 8 处缺陷。这一轮的目标不是把样本数做大，而是
> 专门去找**结构最不规整、体量最大**的那些文书——单位犯罪、审判监督程序、超多被告人、
> 无期徒刑——看它们还能不能把规则撞坏。

## 1. 做了什么

新增 5 份样本（S013–S017），全部为元典智库取得的中文真实生效判决全文，覆盖情形
见 [`12-样本族与覆盖场景.md`](../12-样本族与覆盖场景.md) 第 2 节。选样标准只有一条：
**上一版规则在这份文书上应该是错的**。事后看，5 份里有 4 份真的错了，共撞出 9 处缺陷。

| 样本 | 结构 | 撞出什么 |
| :--- | :--- | :--- |
| S013 鲁0811刑初1080号 | 两个被告单位 + 三名责任人 | 缓刑「三年零六个月」被静默截成 36 个月 |
| S014 金义刑再初字第1号 | 再审改判 + 免予刑事处罚 | 免刑判项罪名抽空；再审首部 0 名被告人；再审双「判决如下」 |
| S015 延中刑再终字第9号 | 再审维持／撤销／改判 | 「撤销」被当成撤销缓刑，形态判成第 77 条 |
| S016 台椒刑初字第570号 | 26 人、27 个判项 | 「二O一四年」（拉丁字母 O）+ 缺「止」字，载明起止日抽不到 |
| S017 苏08刑再2号 | 再审三分项 + 无期 + 主文无判项 | 说理兜底失效；无判项的被告人被报成「抽漏了」 |

## 2. 九处缺陷，分三类

**第一类：静默错误。** 不报错、不留空，值看起来是整数，只有回原文才发现不对。

- 「缓刑三年零六个月」→ 36 个月。缓刑正则把「年」吃进捕获组，取到「三年」就结束。
  同一处还让「缓刑六个月」（拘役案件的标准写法）整条解析失败。新增
  `calc.term_parser.parse_duration_months`，年与月各取一次。
- 载明起止日「自二O一四年三月三日起至二O一八年三月二日」→ 一个都抽不到。两层原因：
  年份只认 `\d{4}`，而原文用拉丁字母 O（码位 0x4F）代零；正则硬性要求「日止」，原文没有「止」。
  中文数字年份必须**逐位**读（「二〇一四」= 2/0/1/4），月日必须**按位值**读（「二十九」=29），
  两者不能共用一个函数。

**第二类：概念混淆。** 同一个词在两种文书里指两件事，规则只认字面。

- 「撤销」在再审里指撤销原判/原判项，在第 77 条里指撤销缓刑。判据从「撤销与缓刑同现」
  改为看**撤销的宾语**：「缓刑宣告」「宣告缓刑」「缓刑…的执行部分」是宾语中心词；
  「缓刑六个月」是量刑，后面紧跟期限，不是宾语。这条同时被 `combination` 与
  `defendant._is_revocation_paragraph` 使用，两处共用一份实现——各自演化一次就会出现
  「形态判定说不是撤销缓刑、罪名抽取说这一项是撤销缓刑」的报告。
- 免予刑事处罚、主文无判项：不是抽取失败，是**结论**。见 ADR-018。

**第三类：兜底失效。** 兜底逻辑写了，但在真实文书上永远不触发。

- 「本院认为……」独立成段、「判决如下：」另起一段时，说理永远取不到——旧实现只在
  含「判决如下」的那一段里找。S017 因此把第 70 条（漏罪）判成第 69 条。改为从**最后一个**
  「本院认为」起、到主文锚点为止，逐段取、按姓名筛句。
- 再审文书全部把原审判决引述一遍，里面有原审自己的「判决如下」。锚点取第一处，主文
  区间就从原审判项开始。改为取最后一处（一审只有一处，等价）。

## 3. 顺手补的两件小事

- `_mark_absent_verdicts`：被告人姓名在主文里零出现即标 `verdict_absent`。
- **S016 当事人姓名改回化名**。上一轮采集时漏改，与「姓名已化名为某」的约定不一致，
  本轮统一补齐（陈某从／尹某丽／张某利／李某仙）。

## 4. 验证

- `python -m pytest -q`：**329 项全绿**（新增 19 项：样本 15、纯正则 2、单元 2）。
- `ruff check src tests tools`：零告警。
- 单条回归：S001–S012 的抽取结果、并罚形态、载明起止日**逐字段比对，无一变化**。
  这是改判据时最需要看的一项——真实样本回归的价值在于「改一处不牵动别处」。

## 5. 还没做的

- 涉黑涉恶的 20 人以上、十余罪名文书。单份正文太长，一次采集会挤占上下文，
  S016 的 26 人只涉一罪，覆盖不到「多人数 × 多罪名」的交叉。
- 二审只改其中一名被告人的写法。S017 是再审的同类结构，二审是否一样还没样本。
- 主文锚点写「判决：」而非「判决如下」的文书。S017 的原审引述用「判决：」，
  但那是被引述的部分，本案主文仍写「判决如下」。
