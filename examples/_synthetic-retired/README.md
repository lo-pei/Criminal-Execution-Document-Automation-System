# 已停用的自编样本

这里的 10 个文件（9 份 TXT + 1 份 PDF）是 2026-10-31 为了覆盖结构多样性**人工构造**
的判决书，2026-11-01 起全部停用，挪到本目录只是因为删除不可恢复，不是还在用。

停用原因：自编样本只能回答「规则被改坏时会不会有人发现」，回答不了「规则在真实
文书上对不对」。写样本的人和写规则的人是同一个人、用同一套想象——换成 12 份真实
生效判决后，第一次跑就暴露出 8 处缺陷，而这 8 处在这批文件上一处都测不出来
（见 `docs/12-样本族与覆盖场景.md` 第 1 节）。

现在：

- **结构覆盖**由 `data/samples/` 下 12 份真实生效判决承担，真值在
  `tests/test_samples.py` 的 `SAMPLES`。
- **`examples/` 根目录只留** `S000`（TXT + PDF 双版本），用途缩到「跑通命令、界面演示、
  TXT/PDF 双通道一致性回归」——真实判决是数据库导出的纯文本，没有软换行与页眉页码，
  测不到清洗层，所以这份基线不能删。
- 本目录**不被任何测试引用**，也不参与任何命中率统计。

若哪天需要恢复某份的写法参考，直接从这里取；但不要再把它当作回归样本。
